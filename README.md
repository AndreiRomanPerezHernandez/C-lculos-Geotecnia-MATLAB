# Desarrollo de Software Geotécnico en MATLAB

Este repositorio contiene una serie de rutinas y scripts desarrollados en MATLAB para automatizar y resolver cálculos complejos de Ingeniería Geotécnica.

## Módulos Desarrollados
* **Bulbo de Esfuerzos:** Script que modela la distribución de esfuerzos en el subsuelo ante cargas aplicadas.
* **Estabilidad de Taludes (Bishop Simplificado):** Algoritmo basado en el método de dovelas para calcular factores de seguridad.
* **Capacidad de Carga (Meyerhof):** Rutina para calcular la capacidad de carga última en cimentaciones superficiales.
* **Muros de Retención:** Análisis de empujes de tierras.

## Tecnologías Utilizadas
* MATLAB
* Enfoque en mecánica de suelos y métodos numéricos aplicados a la ingeniería civil.

*Nota: Estos scripts fueron desarrollados como parte de la formación integral en Ingeniería Civil para agilizar cálculos de gabinete.*
